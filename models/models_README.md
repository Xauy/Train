# `models/` — 3-D модели вагонов по умолчанию

Эта папка содержит OBJ-модели вагонов, используемые SceneWindow по умолчанию,
когда в карточке вагона (Браузер вагонов → колонка «3d модель») не выбран
конкретный файл вручную.

## Как добавить модель по умолчанию

1. Подготовьте файл в формате `.obj`. Ориентация и масштаб не важны:
   SceneWindow сам определит длинную ось, развернёт модель вдоль пути,
   отмасштабирует под длину слота и поставит на рельсы.
2. Скопируйте файл в эту папку.
3. Имя файла должно **точно** совпадать с одним из ожидаемых ниже —
   приложение ищет файлы по фиксированным именам, а не по содержимому.

## Таблица соответствия

| Тип вагона (в выпадающем списке) | Имя файла           |
| -------------------------------- | ------------------- |
| Цистерна                         | `cisterna.obj`      |
| Крытый                           | `kryty.obj`         |
| Полувагон                        | `poluvagon.obj`     |
| Платформа                        | `platforma.obj`     |
| Думпкар                          | `dumpkar.obj`       |
| Хоппер                           | `hopper.obj`        |
| Транспортер                      | `transporter.obj`   |
| Локомотив                        | `locomo.obj`        |

Локомотив в составе нужен для движения поезда в симуляции. На 3D-сцене
модель локомотива разворачивается по ходу движения (нос вперёд).

## Приоритет при выборе модели

Для каждого вагона SceneWindow выбирает первое из:

1. **Явно указанный путь** в карточке вагона
   (кнопка «Выбрать .obj» в Браузере вагонов), если файл существует.
2. **Файл по умолчанию** из этой папки, соответствующий типу вагона,
   если он есть.
3. **Fallback Box** — стандартный синий прямоугольник
   (исходное поведение до появления OBJ-рендера).

То есть отсутствие файла никогда не ломает симуляцию — просто
показывается схематичный «ящик».

## Где это всё определено

Сопоставление «тип → имя файла» хранится в одном месте:
`physics/wagon_defaults.py` → `DEFAULT_MODEL_FILES`. Чтобы добавить
новый тип вагона или переименовать ожидаемый файл, нужно изменить именно
этот словарь (плюс, при необходимости, выпадающий список в
`ui/dialogs/wagons_dialog.py`).
