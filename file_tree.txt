## *.chameleon.json — структура файла проекта (v0.2)

```json
{
  "version": "0.2",
  "paths":   [ <PathRecord>,     ... ],
  "dkps":    [ <DKPRecord>,      ... ],
  "wagons":  [ <WagonRecord>,    ... ],
  "train":     <TrainRecord>,
  "scenario":  <ScenarioRecord>
}
```

| Запись | Ключевые поля |
|---|---|
| `PathRecord` | `track_id`, `name`, `x1/y1/z1`, `x2/y2/z2` *(length_mm вычисляется)* |
| `DKPRecord` | `sensor_id`, `track_id`, `s_mm`, `sensor_type`, `enabled`, `direction_filter`, `zone_mm` |
| `WagonRecord` | `wagon_id`, `name`, `wagon_type`, `length_mm`, `height_mm`, `bogie_base_mm`, `axles[]`, `model_path` |
| `TrainRecord` | `train_id`, `track_id`, `s0_mm`, `direction`, `wagon_sequence[]` |
| `ScenarioRecord` | `scenario_id`, `name`, `steps[]` |
| `ScenarioStep` | `duration_ms`, `v0_mms`, `accel_mms2`, `v_threshold_mms`, `behavior` |
